# Architecture

## 목표

이 프로젝트는 서버를 운영하지 않고도 OPIc 말하기 연습을 제공하는 단일 페이지 앱입니다. 모든 세션 상태와 질문 편집 데이터는 사용자의 브라우저에 저장되며, 선택한 평가 방식에 따라 음성 전사와 피드백 경로가 달라집니다.

## 런타임 구성

### 입력 계층

- `SpeechSynthesisUtterance`: 영어 질문을 재생합니다.
- `MediaRecorder`: 답변 원본을 녹음합니다.
- `getUserMedia`: 세션에서 하나의 마이크 스트림을 재사용합니다.
- 질문 재생 횟수와 답변 원문은 브라우저 저장소에 기록합니다.

### 전사 계층

1. 로컬 Whisper가 준비되면 `whisper.cpp` WASM과 `ggml-base.en-q5_1.bin`을 사용합니다.
2. OpenAI 선택 시 `/v1/audio/transcriptions`의 `gpt-4o-mini-transcribe`를 사용합니다.
3. Gemini 선택 시 Gemini Flash의 오디오 입력을 사용합니다.
4. 로컬 Whisper를 준비하지 않은 경우에만 브라우저 음성 인식을 보조 경로로 사용합니다.

Whisper 모델은 IndexedDB에 캐시되며, 실제 추론은 브라우저의 WASM 런타임에서 수행됩니다. 최대 2분 답변을 처리할 수 있도록 녹음 종료 후 오디오를 16kHz mono PCM으로 변환합니다.

### 평가 계층

- 규칙 평가: 단어 수, 문장 구성, 연결어, 어휘 반복, 멈춤 신호를 계산합니다.
- 로컬 LLM: WebGPU가 가능한 환경에서만 선택적으로 실행되며 규칙 평가를 보조합니다.
- 온라인 AI: OpenAI 또는 Gemini 응답은 JSON 평가 형식으로 정규화합니다.
- 온라인 평가 실패 시 해당 문항은 규칙 평가로 안전하게 대체합니다.

평가 작업은 `evaluationJobs`로 추적하고, 다음 문항을 푸는 동안 완료되도록 비동기 처리합니다. 제출 시점에는 답변이 저장된 문항만 평균에 포함합니다.

## 저장 데이터

| 데이터 | 저장 위치 | 목적 |
| --- | --- | --- |
| 진행 상태·답변·피드백 | `localStorage` | 중단 후 재개 |
| 질문 편집 내용 | `localStorage` | 사용자별 질문 목록 유지 |
| Whisper 모델 | `IndexedDB` | 약 57MB 모델 재다운로드 방지 |
| API 키 | `localStorage` | 사용자가 저장을 선택한 경우 재연결 |

API 키는 암호화된 비밀 저장소가 아닙니다. 공용 PC에서는 저장하지 않는 것을 권장합니다.

## 배포

GitHub Pages와 같은 정적 호스팅에 `index.html`을 게시할 수 있습니다. 마이크와 WASM 권한 문제를 줄이기 위해 HTTPS 또는 `localhost` 환경을 사용합니다. 별도 서버가 없기 때문에 서버 측 사용자 계정, 개인별 사용 기록, 서버 로그 기반 분석은 제공하지 않습니다.

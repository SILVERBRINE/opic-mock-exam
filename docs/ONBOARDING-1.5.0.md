# v1.5.0 시작 흐름

- 홈에는 녹음본만 표시한다. Kokoro는 미리 생성할 때 사용한다. 시험 재생은 검증된 캐시만 읽으며 생성/브라우저 TTS 대체를 하지 않는다.
- 기본 API는 Gemini이며 Gemini, OpenAI 순서로 표시한다. 이전 local 설정은 시작 시 Gemini로 전환하고 API 키·히스토리는 유지한다. 오프라인 선택은 API 미연결 시작 안내창에서만 제공한다.
- 시작 버튼은 aria-disabled로 준비 대기 상태를 알리되, 생성 안내를 열 수 있도록 클릭과 키보드 접근을 유지한다. 실제 생성 중에는 중복 시작 요청을 무시한다.
- 초기 로드와 시작 요청에서 현재 질문은행의 캐시를 검사한다. 일부 누락/손상, 질문 변경, 캐시 삭제, 저장 실패에는 준비 완료로 처리하지 않는다.
- 생성 완료 후에는 자동으로 시험을 시작하지 않는다. 사용자가 시작하면 API 연결 상태를 확인하고, 미연결이면 좌측부터 오프라인으로 시작, API 설정, 우측 닫기를 제공한다.
- API 설정은 평가 방식 제목으로 스크롤하고 포커스를 이동한다. 확인창은 native dialog로 키보드 포커스를 제한하며 Escape로 닫을 수 있다.

## 검증

onboarding-regression은 신규/기존 설정, 준비 안내, 생성 트리거, 실제 일괄 생성 제어 흐름의 저장 실패·성공(추론만 모의 처리), API 안내 버튼 순서·포커스·닫기·오프라인 시작, 연결된 API의 두 시작 경로, 캐시 삭제와 시험 중 생성 금지를 확인한다. 기존 회귀 검사도 수행한다. 이 UI 변경을 위해 실제 200문항 전체 재생성이나 유료 API 요청은 수행하지 않는다.

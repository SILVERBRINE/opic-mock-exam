# v1.4.4 채점 변경

## 앱의 기준

완성도는 질문이 요구한 설명·비교·경험·결과의 의미적 충족, 유창성은 전사에서 확인 가능한 연결과 전개, 정확성·명확성은 시제·수 일치·품사·문장 구조·어휘가 의미 전달에 미치는 영향으로 평가한다. 발음은 텍스트로 확인할 수 없어 점수 카드를 제거하고 총점에서 제외한다. 기존 기록은 원래 점수를 보존하며 이전 기준임을 표시한다.

사용자가 제시한 도로 공사 답변처럼 배경, 문제, 대응, 결과, 이후 습관을 상세하고 연결되게 설명하는 수준을 앱 AL 참고 기준(대략 9/9/8~9)으로 삼는다. 특정 주제나 단어 수를 만족하면 점수를 보장하는 규칙은 아니다. 공식 OPIc 등급 보정 자료가 아니며 앱의 연습 기준이다. AI가 만든 답변이라는 이유만으로 AL을 부여하지 않는다.

## 처리

- API 단일 채점, 제출 후 묶음 채점, 로컬 LLM이 동일한 짧은 영어 기준을 사용한다. 로컬 피드백은 영어, API 피드백은 한국어다.
- 항목별 짧은 근거 필드를 응답 스키마에 요청하고 평가 근거에 표시한다. 모호한 STT 단어와 어미를 발음 오류로 확정하지 않으며 동일한 결함의 중복 감점을 금지한다.
- 키워드 일치율에 따른 점수 상한은 제거한다. 마이크 테스트·무의미한 반복에 대한 보호 검사는 유지한다.
- 공통 조언을 자동으로 생성하지 않는다. 제공된 구체적 팁을 표시하고, 없는 경우 제공되지 않았다고 표시한다.
- 총점은 측정 가능한 세 항목의 평균이다. 이전 4항목 점수를 새 방식으로 몰래 재계산하지 않는다. 재채점 캐시는 새 기준 식별자로 구분한다.

## 검증 범위

자동 회귀 검사는 키워드 불일치에도 의미 평가 점수가 보존되는지, 9/9/8이 87점인지, STT confidence가 총점을 바꾸지 않는지, 세 점수 카드와 근거 출력, 마이크 테스트 보호, 짧은 프롬프트 및 녹음·API 재시도·묶음 채점 흐름을 확인한다. 모의 API 응답은 요청·파싱·화면 검증이며 Gemini 실서비스가 항상 원하는 점수를 준다는 증거가 아니다. API 키 없이 실제 Gemini 점수와 응답 속도를 측정하지 않았다.

실제 음성의 속도·억양·발음은 이 버전에서 측정하지 않는다. STT가 잘못 인식한 단어와 실제 발화 오류를 완전히 구분할 수 없으며, 프롬프트의 불확실성 처리도 모델별 편차가 있을 수 있다.

실제 Llama 3.2 1B 실행에서 준비 검사와 새 8필드 JSON 출력이 완료되었고 발음은 null이었다. 다만 일부 항목 근거는 구체적 인용 대신 일반적 설명을 반환했다. 출력 형식의 동작 확인과 채점 품질 보장은 구분하며, 로컬 모델의 임시 참고 평가 표시는 유지한다.

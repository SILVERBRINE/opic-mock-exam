## 실행 명령

- `node scripts/session-regression.cjs`
- `node scripts/worker-lifecycle-regression.cjs`
- `node scripts/local-tts-smoke.cjs` (네트워크와 실제 모델 다운로드 필요, 기본 CI 제외)
- `node scripts/local-whisper-smoke.cjs` (실제 WASM·base.en Q5_1·공식 JFK 샘플, 기본 CI 제외)

### 실제 Whisper 실행 결과

추가로 실행 파일도 초기화 성공 후 IndexedDB에 저장하도록 수정했다. 첫 전사 후 모든 외부 HTTPS 요청을 차단하고 페이지를 새로고침한 뒤, 캐시된 실행 파일·모델·샘플로 동일한 실제 전사가 성공했다. 앱 HTML을 제공하는 localhost는 유지한 테스트다.

COOP/COEP가 적용된 localhost와 Edge에서 실제 모델을 다운로드해 전사했다. 원래 코드는 외부 main.js를 Worker로 실행하려다 SecurityError가 발생했고, Blob URL 로딩 수정 후에는 초기화 이후 print 교체가 반영되지 않아 시간 초과됐다. 초기화 시 유지되는 출력 디스패처로 수정한 뒤 공식 JFK 샘플에서 “And so my fellow Americans, ask not what your country can do for you, ask what you can do for your country.”를 반환하고 정상 종료했다.

### 실제 TTS 실행 결과

200문항 전체를 Edge에서 실제 Kokoro 워커 4개로 생성했다. 실패 0건, 총 1,597,212ms(약 26분 37초)였고 각 문항의 WAV 구조·신호·디코딩·IndexedDB 저장 후 재읽기를 검증했다. 세부 기록과 검사 대상 소스 해시는 `local-tts-validation.json`에 있다. 음성 내용의 정확성을 사람이 청취하거나 별도 STT로 대조한 검사는 포함하지 않는다.

Edge headless, WASM 워커 1개, 실제 Kokoro 모델로 실행했다. 초기화 이후 생성·검증·저장·재읽기에 29,305ms가 걸렸다. WAV는 370,844바이트, 24kHz 모노 PCM16, 길이 7.725초였으며 디코딩 길이도 일치했다. 저장 후 메모리 캐시를 비운 뒤 IndexedDB에서 다시 읽은 크기도 동일했다. 이 결과는 한 문항의 실행 증거이며 200문항 전체나 다른 하드웨어의 성능을 보장하지 않는다.

## 사용자가 복구할 수 있는 경로

- 브라우저 저장소 사용 실패: 메모리에서 연습을 계속하고 종료 전 기록 내보내기.
- 전사 실패: 원본 녹음 다운로드, 같은 녹음으로 재시도, API 키 재연결.
- 온라인 평가 실패: API 설정 유지, 실패 사유와 임시 규칙 점수 표시, 예상 등급 판정 보류.
- 업데이트 감지: 사용 중에는 자동 새로고침하지 않고 연습 종료 후 새로고침 안내.

전체 출시 준비 완료 상태는 아니다. 미검증 항목은 통과로 간주하지 않는다.

- GitHub Actions Linux/Chromium 검증 성공: https://github.com/SILVERBRINE/opic-mock-exam/actions/runs/34324266585
- Edge 파일 실행: 360/768/1920px 설정·연습·평가·최종 결과 화면과 읽기 전용 전사 확인.
- 마이크 분리 이벤트 및 녹음본 재생 완료 이벤트 누락을 재현하고 복구 확인.

- 실제 공급자 키와 전문가 정답 데이터가 없어 온라인 채점 품질을 검증한 것으로 간주하지 않는다.

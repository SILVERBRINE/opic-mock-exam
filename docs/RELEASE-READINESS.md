# 출시 안정성 검토 현황

검토 범위와 증거, 검증의 한계를 기록한다. 자동 회귀 테스트는 모의 API를 사용하는 Edge 및 GitHub Actions의 Chromium에서 실행한다. 실제 모델 실행과 패키지 검증은 아래에 별도로 기록했다.

| 범위 | 현재 증거 | 운영상 제한 |
|---|---|---|
| 녹음 | 실제 MediaRecorder 가상 마이크 캡처, 지연 이벤트 분리, 권한 거절·장치 없음·생성 실패 시 스트림 해제, 장치 종료 이벤트 및 이탈 취소 시 녹음 유지 테스트 | 실제 물리 장치별 드라이버 동작은 환경 차이가 있음 |
| 전사 실패 복구 | 빈 응답 재시도, 원본 보존·다운로드, 키 재연결, 전체 시간 만료 시 실패 녹음 보존 테스트 | 녹음 원본은 탭 메모리이므로 새로고침 전 다운로드 필요 |
| Gemini 평가 | 공식 API 문서와 요청 형식 대조. 스키마, 잘린 응답, 차단, 오류, 429 전환, 최대 3회 전환 테스트. 전환 묶음마다 총 90초 제한 | 실제 개인 API 키 호출 미검증; 공급자 정책·계정별 권한은 변동 가능 |
| OpenAI | 요청 헤더·본문 대기 제한, GPT-4/5별 요청 옵션과 정상 응답 경로 회귀 검증 | 실제 개인 API 키 호출 미검증 |
| 로컬 AI | 실제 Whisper 전사 및 네트워크 차단 후 재실행, 모델 해시 검증, 손상 캐시 복구. 실제 LLM 실행 및 불완전 응답 거부, 실패 엔진 격리 | 소형 LLM의 평가 품질은 확인된 한계이며 임시 점수로 표시 |
| TTS | 실제 Kokoro 200문항을 워커 4개로 생성·검증·저장·재읽기 완료, 실패 0건. 저장 실패 중단 및 재생 이벤트 누락 복구 테스트 | 음성 내용의 전문 청취 검수와 모든 사양의 성능은 보장하지 않음 |
| 시험 진행 | 15문항 진행·평가·최종 제출·기록 저장, 녹음 중 이동 차단. 새로고침 후 문항·답변·점수·듣기 횟수·타이머 복원 검증 | 처리 전 원본은 자동 영구 저장하지 않음 |
| 타이머 | 지연 콜백 경과 시간 보정, 시작 시 초 감소 방지, 시간 0초 시 전사 실패 복구 테스트 | 연습 보조도구이므로 재개 시 저장된 남은 시간을 사용하며 앱을 닫아 둔 시간은 차감하지 않음 |

| 출시 자동화 | 고정 의존성 npm ci 및 npm test, GitHub CI 성공. Pages·릴리즈 검증 선행, 태그·HTML 버전 일치 검사, ZIP 압축 해제 후 실행 확인 | 현재 작업은 검토 PR이며 공개 배포·새 버전 발행은 별도 단계 |

## 실행 명령

### 후속 UX 변경 검증

`scripts/background-exam-regression.cjs`: 사고 설정 미지원 400 응답의 제한된 재시도, 모의고사 다음 문항 이동 중 이전 전사 완료, 현재 답변·음성 지표 격리, 전사 완료 초록 표시, 완료 순서가 뒤바뀐 평가와 전체 제출 대기, Whisper 순차 대기열, 연습모드 이어하기 제거를 검증한다. 연습모드는 진행 상태를 저장·복원하지 않으며 완료 기록은 유지한다. 모의고사 진행 복원은 유지한다.

- `node scripts/session-regression.cjs`
- `node scripts/worker-lifecycle-regression.cjs`
- `node scripts/local-tts-smoke.cjs` (네트워크와 실제 모델 다운로드 필요, 기본 CI 제외)
- `node scripts/local-whisper-smoke.cjs` (실제 WASM·base.en Q5_1·공식 JFK 샘플, 기본 CI 제외)

### 실제 Whisper 실행 결과

추가로 실행 파일도 초기화 성공 후 IndexedDB에 저장하도록 수정했다. 첫 전사 후 모든 외부 HTTPS 요청을 차단하고 페이지를 새로고침한 뒤, 캐시된 실행 파일·모델·샘플로 동일한 실제 전사가 성공했다. 앱 HTML을 제공하는 localhost는 유지한 테스트다.

COOP/COEP가 적용된 localhost와 Edge에서 실제 모델을 다운로드해 전사했다. 원래 코드는 외부 main.js를 Worker로 실행하려다 SecurityError가 발생했고, Blob URL 로딩 수정 후에는 초기화 이후 print 교체가 반영되지 않아 시간 초과됐다. 초기화 시 유지되는 출력 디스패처로 수정한 뒤 공식 JFK 샘플에서 “And so my fellow Americans, ask not what your country can do for you, ask what you can do for your country.”를 반환하고 정상 종료했다.

### 실제 TTS 실행 결과

200문항 전체를 Edge에서 실제 Kokoro 워커 4개로 생성했다. 실패 0건, 총 1,597,212ms(약 26분 37초)였고 각 문항의 WAV 구조·신호·디코딩·IndexedDB 저장 후 재읽기를 검증했다. 세부 기록과 검사 대상 소스 해시는 `local-tts-validation.json`에 있다. 음성 내용의 정확성을 사람이 청취하거나 별도 STT로 대조한 검사는 포함하지 않는다.

Edge headless, WASM 워커 1개, 실제 Kokoro 모델로 실행했다. 초기화 이후 생성·검증·저장·재읽기에 29,305ms가 걸렸다. WAV는 370,844바이트, 24kHz 모노 PCM16, 길이 7.725초였으며 디코딩 길이도 일치했다. 저장 후 메모리 캐시를 비운 뒤 IndexedDB에서 다시 읽은 크기도 동일했다. 이 결과는 한 문항의 실행 증거이며 200문항 전체나 다른 하드웨어의 성능을 보장하지 않는다.

## 사용자가 복구할 수 있는 경로

- 브라우저 저장소 사용 실패: 메모리에서 연습을 계속하고 종료 전 기록 내보내기.
- 전사 실패: 원본 녹음 다운로드, 같은 녹음으로 재시도, API 키 재연결.
- 온라인 평가 실패: API 설정 유지, 실패 사유와 임시 규칙 점수 표시, 예상 등급 판정 보류.
- 업데이트 감지: 사용 중에는 자동 새로고침하지 않고 연습 종료 후 새로고침 안내.

이 검토는 발견된 결함의 수정과 장애 복구, 지원 경로의 회귀 검증을 다룬다. 모든 하드웨어의 무결함이나 AI 채점의 공식 시험 일치를 보장하지 않는다. 특히 실제 API 키 호출과 전문가 채점 대조는 통과한 것으로 간주하지 않는다. 공개 Pages·릴리즈는 검토 브랜치를 배포하기 전까지 기존 버전이다.

### 추가 검증 결과

- GitHub Actions Linux/Chromium 검증 성공: https://github.com/SILVERBRINE/opic-mock-exam/actions/runs/34324266585
- Edge 파일 실행: 360/768/1920px 설정·연습·평가·최종 결과 화면과 읽기 전용 전사 확인.
- 마이크 분리 이벤트 및 녹음본 재생 완료 이벤트 누락을 재현하고 복구 확인.
- 실제 로컬 Llama 3.2 1B 실행은 성공했지만 평가 품질은 통과하지 못했다. 빈 개선 설명 또는 잘못된 필드 이름과 예문에 반하는 지적이 나왔다. 필수 설명 누락 응답은 거부하며, 정상 형식이어도 오프라인 혼합 점수는 임시 참고 점수로 처리한다.
- 실제 공급자 키와 전문가 정답 데이터가 없어 온라인 채점 품질을 검증한 것으로 간주하지 않는다.
- Whisper 모델은 공식 저장소 커밋 5359861c739e955e79d9a303bcbc70fb988958b1로 고정했다. 파일 크기 59,721,011바이트와 SHA-256 4baf70dd0d7c4247ba2b81fafd9c01005ac77c2f9ef064e00dcf195d0e2fdd2f를 확인한다. 손상 캐시 재다운로드 및 불완전 다운로드의 저장·실행 차단 테스트 통과. 실제 모델의 전사와 외부 네트워크 차단 후 재실행도 다시 통과했다.
- 기존 릴리즈 ZIP은 재실행으로 삭제·교체하지 않아 다운로드 집계를 보존한다. 태그와 HTML 표시 버전이 다르면 패키징을 거부한다.

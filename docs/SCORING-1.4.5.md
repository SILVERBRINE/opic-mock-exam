# v1.4.5 AI 점수 덮어쓰기 제거

`check this`를 마이크 테스트로 오인하여 내용 1·유창성 2·정확성 2로 강제 변경하던 규칙과, 이후 추가한 테스트 어휘 목록까지 모두 삭제했다. 키워드·동의어·반복률 검출 헬퍼도 제거했다. 내용의 적합성은 문항과 전체 답변을 받는 AI가 평가한다. 프롬프트의 마이크 테스트 전용 지시도 삭제했다.

API 단일 채점, 모의고사 묶음 채점, 로컬 AI 결과에 공통으로 적용한다. 후처리는 측정 가능한 세 항목의 평균만 계산하며, 답변 문구로 점수·근거·개선 의견을 변경하지 않는다. 로컬 모델 결과에 규칙 조언을 채워 넣던 처리도 제거했다. 응답 JSON의 숫자 범위·완료 여부, 전사 오류, 녹음 누락 등 기술 검사는 유지한다.

AI가 없는 경우의 오프라인 기본 규칙 평가는 별도 임시 참고 기능으로 남아 있다. 성공한 AI 결과에는 섞지 않는다. 기존 히스토리는 원점수 보존이며, 이번 기준의 재채점 캐시는 이전 버전과 구분한다.

회귀 검증은 정상 아침 루틴, `check this`, 짧은 반복 문장, 테스트를 언급하는 실제 경험, 테스트 문구 자체에 대해 모델 점수가 보존되는지 확인한다. 테스트 문구에 높은 점수를 부여하라는 뜻이 아니라, 관련성 판단을 모델에 맡긴다는 뜻이다. Gemini 실서비스의 채점 품질은 API 키 없이 검증하지 않았으며 모델 자체의 편차는 남아 있다.

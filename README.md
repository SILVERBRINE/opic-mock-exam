## v1.5.0 업데이트

- 문항 음성을 녹음본으로 통일하고 처음 시작하는 화면을 단순화했습니다.
- Gemini API를 맨 왼쪽 기본 선택으로 배치했습니다.
- 녹음본이 없으면 시작 버튼에서 생성 안내가 열립니다. 확인을 누르면 준비를 시작합니다.
- 녹음본 준비 후 API가 연결되지 않았다면 오프라인 시작·API 설정·닫기를 선택할 수 있습니다.
- API 설정을 선택하면 홈의 평가 방식 영역으로 바로 이동합니다.

## 처음 시작하기

1. 최신 릴리즈 ZIP을 내려받아 압축을 풀고 **OPIc 연습 시작.html**을 더블클릭합니다. 확장자가 숨겨져 있으면 **OPIc 연습 시작**으로 보입니다. `coi-serviceworker.js`는 같은 폴더에 두세요.
2. **모의고사 시작** 또는 **연습 모드**를 누릅니다. 녹음본이 없다면 안내창에서 **확인**을 눌러 생성합니다.
3. 200문항 녹음본 준비를 기다립니다. PC 사양에 따라 30분 이상 걸릴 수 있습니다. 저장된 문항은 다음 준비에서 재사용합니다.
4. 평가 방식의 **Gemini API**에 키를 붙여 넣고 **연결**을 누릅니다. OpenAI API도 선택할 수 있습니다.
5. 시작 버튼을 눌러 연습합니다. API를 연결하지 않았다면 안내창의 **오프라인으로 시작**으로 진행할 수 있습니다.

오프라인은 별도의 평가 메뉴 없이 시작 안내창에서 선택합니다. AI가 준비되지 않은 경우 기본 참고 평가를 사용하며, 브라우저 음성 인식은 환경에 따라 인터넷이 필요할 수 있습니다. 더 정밀한 전사·평가에는 API 연결을 권장합니다.

## 녹음본과 기록

문제는 녹음본으로만 재생합니다. 준비되지 않은 음성을 브라우저 TTS로 대체하거나 시험 중 자동 생성하지 않습니다. 소리 테스트는 스피커 확인음을 재생합니다.

녹음본은 Kokoro 음성 모델로 PC에서 생성하고 WAV 구조·길이·신호·디코딩을 검사합니다. 저장 실패나 생성 실패가 있으면 시작 버튼은 준비 대기 상태를 유지합니다. 질문을 수정하거나 녹음본을 삭제한 경우 다시 준비해 주세요.

생성한 녹음본은 같은 브라우저·사이트의 IndexedDB에 보관됩니다. HTML 파일과 함께 이동하지 않으며 사이트 데이터 삭제나 비공개 창 종료 시 사라질 수 있습니다. 기존 히스토리는 보존되며 앱의 기록 백업·가져오기로 옮길 수 있습니다.

모의고사는 15문항, 연습 모드는 한 문항씩 진행합니다. API 모의고사는 전사를 백그라운드로 처리하고 제출 후 묶음 채점합니다. 연습 모드는 답변마다 피드백을 확인합니다. 모의고사는 최대 2문항을 건너뛰어 채점에서 제외할 수 있습니다.

## Gemini API 키 발급 [무료]

API 방식을 쓰면 오프라인 기본 평가보다 음성 전사와 답변 분석이 더 정밀해져서, 연습 피드백 품질을 높일 수 있음. Google AI Studio의 무료 사용량과 정책은 계정·시점에 따라 달라질 수 있으니 발급 화면에서 확인하면 됨.

[Google AI Studio API 키 발급 페이지](https://aistudio.google.com/app/apikey)

1. Google 계정으로 로그인
2. **API key 만들기** 클릭
3. 키 복사해서 앱의 Gemini API 입력란에 붙여 넣기
4. **연결** 누르면 사용 가능한 최신 Flash 모델 확인 가능

Gemini **Auto · 3.5 / 3.1 Flash-Lite 교대**는 연결 목록에 있는 `gemini-3.5-flash-lite`와 `gemini-3.1-flash-lite`만 교대로 사용합니다. 한 후보가 일시적으로 실패하면 다른 후보를 시도하며, 둘 다 사용할 수 없으면 답변을 보존합니다. API 모의고사는 제출 시 5문항씩 채점하고, 실패한 경우 전체 제출로 미채점 묶음만 다시 요청할 수 있습니다. 같은 채점 기준을 적용하지만 모델 간 점수의 완전한 일치는 보장하지 않습니다. 탭 내부 요청 집계는 계정 전체 잔여량이 아닙니다.

API 키는 Google API로 직접 전송됩니다. 같은 탭의 세션 저장소에 제공자별로 보관하므로 새로고침과 평가 방식 변경 후에도 유지됩니다. 공용 PC에서는 사용 후 키 삭제를 눌러 주세요. 브라우저의 탭 복원 기능은 세션을 복원할 수 있습니다.

히스토리는 같은 Pages 주소의 브라우저 저장소에 자동으로 이어집니다. 새로 받은 HTML이나 다른 브라우저로 옮길 때는 앱의 **히스토리 → 기록 백업**으로 JSON을 내려받은 뒤, 새 환경에서 **백업 가져오기**를 누르면 기존 기록과 합쳐집니다.



## 구조

```text
index.html                         정적 앱 진입점·UI·질문 데이터
docs/ARCHITECTURE.md                실행·평가·저장 흐름
```

질문 문제은행 200개는 별도 문서가 아니라 `index.html` 안에 들어 있어요. 앱의 **연습 질문 수정**에서 바꾼 내용은 지금 쓰는 브라우저에만 저장됩니다.

앱은 다음 순서로 동작합니다.

```text
검증된 캐시 녹음본으로 문항 재생
  -> 마이크 녹음
  -> 브라우저 MediaRecorder로 원본 확보
  -> 오프라인 Whisper 또는 선택한 API로 전사
  -> 규칙 평가 + (선택) 로컬 LLM / 온라인 AI 평가
  -> 문항 피드백 저장
```

API를 선택해도 별도 중계 서버를 거치지 않습니다. 따라서 사용자의 API 키와 음성 데이터는 선택한 제공자의 브라우저 API 요청으로 직접 전달됩니다.

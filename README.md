## v1.1 업데이트

- 연습모드에서 문항 음성을 제한 없이 반복 재생
- Kokoro 로컬 TTS와 200문항 녹음본 캐시 지원
- 200문항 녹음본 일괄 생성은 PC 사양과 브라우저에 따라 30분 이상 걸릴 수 있음
- 일괄 생성 로딩창에 `0/200`부터 문항별 진행 상황 표시
- 생성한 WAV는 구조·신호·브라우저 디코딩을 확인하고, 문제가 있으면 자동 재생성
- 브라우저가 제공하는 코어·메모리 정보와 생성 상태를 기준으로 동시 생성 수를 자동 조정

## 주요 기능

- OPIc 유형의 영어 질문 200개 문제은행과 역할극 문항
- 질문은 음성으로만 제공되며, 모의고사는 한 문항당 최대 2회, 연습모드는 제한 없이 반복 재생
- 브라우저 TTS, Kokoro 로컬 TTS, Kokoro가 만든 문항 녹음본(WAV 캐시) 중 선택
- 로컬 TTS를 한 번 준비하면 200문항 녹음본을 한 번에 미리 만들거나 필요한 문항만 자동 생성 가능 (PC 사양과 브라우저에 따라 전체 생성에 30분 이상 걸릴 수 있음)
- 녹음본은 저장 전후에 WAV 헤더·재생 시간·무음 여부·실제 디코딩을 검사하며, 실패한 문항은 최대 3회까지 다시 생성
- 음성 답변 원문은 수정할 수 없게 고정
- 문항 듣기를 누른 시점부터 문항별 2분 타이머 시작
- 마이크 스트림을 세션 중 재사용해 반복 권한 요청 최소화
- 다음 문항으로 이동하는 동안 전사와 평가를 백그라운드 처리
- 진행 중인 문항만으로 즉시 제출하는 모의고사 모드
- 한 문항 피드백 후 새 문제를 계속 푸는 연습모드
- Intermediate Low부터 Advanced Low까지의 OPIc 예상 등급 표시

## 실행

1. 저장소의 `index.html` 다운 ㄱㄱ
2. 마이크 권한이 꼬이지 않게 Chrome이나 Edge에서 `localhost`/HTTPS로 열면 됨.
3. 아래에서 **평가 방식** 고르면 됨.
   - **오프라인 기본 평가**: 인터넷 없이 규칙 기반 평가
   - **오프라인 Whisper**: `whisper.cpp`의 양자화 `base.en Q5_1` 모델(약 57MB)을 브라우저 저장소에 내려받아 로컬 전사
   - **OpenAI API / Gemini API**: 전사와 답변 평가가 더 정확하고 고품질로 나올 수 있지만 개인 API 키가 필요함

문항 음성 방식은 홈 화면의 **문항 음성 방식**에서 고르면 됨.

- **브라우저 TTS**: 별도 다운로드 없이 운영체제 음성으로 바로 재생
- **로컬 TTS**: Kokoro-82M 양자화 모델(약 86MB)을 브라우저에 내려받아 WebGPU 또는 WASM으로 PC 안에서 생성
- **녹음본**: Kokoro가 만든 질문 WAV를 IndexedDB에 캐시해 다음부터 파일처럼 재생. **200문항 녹음본 미리 만들기**를 누르면 한 번에 준비하고, 누르지 않으면 필요한 문항을 첫 재생 때 자동 생성합니다. 전체 생성은 PC 사양과 브라우저에 따라 30분 이상 걸릴 수 있습니다.

녹음본 일괄 생성은 브라우저가 정확한 CPU 사용률을 제공하지 않기 때문에, 논리 코어 수·장치 메모리·JS 힙 압박·입력 지연·최근 생성 결과를 보고 동시 생성 수를 1~3개 범위에서 조절합니다. Kokoro WASM/WebGPU 추론 자체가 잠시 메인 스레드를 바쁘게 만들 수 있어 생성 중 화면이 순간적으로 끊길 수 있으며, WAV 변환·검증 사이에는 화면이 갱신될 수 있도록 양보합니다.

로컬 TTS 모델과 질문 녹음본은 사용자 답변 음성과 별개입니다. 질문 음성은 브라우저에만 저장되고, 사용자의 답변 원본 녹음은 전사 후 메모리에서 해제됩니다.

오프라인 Whisper 모델은 브라우저의 IndexedDB에 저장돼요. 첫 준비 때 whisper.cpp 실행 파일과 모델을 외부에서 내려받고, 이후에는 캐시된 모델을 재사용합니다. Kokoro 모델과 질문 녹음본도 브라우저 캐시에 저장됩니다. 비공개 모드에서는 브라우저를 닫을 때 저장 데이터가 사라져서 다시 받을 수 있습니다.

## Gemini API 키 발급 [무료]

API 방식을 쓰면 오프라인 기본 평가보다 음성 전사와 답변 분석이 더 정밀해져서, 연습 피드백 품질을 높일 수 있음. Google AI Studio의 무료 사용량과 정책은 계정·시점에 따라 달라질 수 있으니 발급 화면에서 확인하면 됨.

[Google AI Studio API 키 발급 페이지](https://aistudio.google.com/app/apikey)

1. Google 계정으로 로그인
2. **API key 만들기** 클릭
3. 키 복사해서 앱의 Gemini API 입력란에 붙여 넣기
4. **연결** 누르면 사용 가능한 최신 Flash 모델 확인 가능

Gemini 모델을 **Auto · 한도 분산**으로 두면 연결된 텍스트 Flash 모델을 문항마다 순환합니다. 한 모델에서 429(한도 초과)·권한 오류·시간 초과가 나면 다음 후보로 재시도하고, 모두 실패하면 해당 답변은 오프라인 기본 평가로 이어집니다. 이 방식은 현재 탭에서 보낸 요청만 추적하는 최선의 보호책이라 계정 전체의 실제 사용량이나 다른 탭의 요청까지 보장하지는 않습니다. 전사와 채점은 한 문항 안에서 같은 실제 모델을 사용하고, 모든 모델에 같은 평가 프롬프트와 1~10 기준을 적용합니다.

API 키는 이 정적 페이지에서 Google API로 직접 전송됨. 키는 브라우저 저장소에 저장하지 않아서 새로고침하면 다시 입력해야 함. 키를 저장소나 다른 사람에게 공유하지 말고, Google AI Studio에서 사용량·제한을 확인하면 됨.

히스토리는 같은 Pages 주소의 브라우저 저장소에 자동으로 이어집니다. 새로 받은 HTML이나 다른 브라우저로 옮길 때는 앱의 **히스토리 → 기록 백업**으로 JSON을 내려받은 뒤, 새 환경에서 **백업 가져오기**를 누르면 기존 기록과 합쳐집니다.

로컬 Whisper WASM은 `coi-serviceworker.js`가 있는 HTTPS Pages 또는 `localhost`에서 준비하는 것이 안정적입니다. 파일을 직접 열거나 비공개 모드에서 실행하면 서비스 워커·IndexedDB가 제한될 수 있어 브라우저 음성인식과 규칙 평가로 자동 대체됩니다.

## 구조

```text
index.html                         정적 앱 진입점·UI·질문 데이터
docs/ARCHITECTURE.md                실행·평가·저장 흐름
```

질문 문제은행 200개는 별도 문서가 아니라 `index.html` 안에 들어 있어요. 앱의 **연습 질문 수정**에서 바꾼 내용은 지금 쓰는 브라우저에만 저장됩니다.

앱은 다음 순서로 동작합니다.

```text
브라우저 TTS 또는 Kokoro 로컬 TTS·캐시 녹음본으로 문항 재생
  -> 마이크 녹음
  -> 브라우저 MediaRecorder로 원본 확보
  -> 오프라인 Whisper 또는 선택한 API로 전사
  -> 규칙 평가 + (선택) 로컬 LLM / 온라인 AI 평가
  -> 문항 피드백 저장
```

API를 선택해도 별도 중계 서버를 거치지 않습니다. 따라서 사용자의 API 키와 음성 데이터는 선택한 제공자의 브라우저 API 요청으로 직접 전달됩니다.
